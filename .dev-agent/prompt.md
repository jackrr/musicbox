This project builds for Android (primary) and iOS. Audio is generated by
a Rust cdylib in `engine/`; UI is Flutter in `app/`. After any Rust change you
must rebuild the native lib via `scripts/build_android.sh` — Flutter hot reload
will not pick up Rust changes.

Useful commands:
- `cd engine && cargo check` — fast Rust type-check
- `cd engine && cargo test`  — Rust unit tests
- `./scripts/build_android.sh` — rebuild native lib for Android (add `--dev` for debug)
- `cd app && flutter analyze` — static analysis
- `cd app && flutter test`    — Dart tests

The Rust↔Dart command protocol is documented in `CLAUDE.md`. The enums in
`app/lib/engine/types.dart` MUST match `engine/src/commands.rs` exactly.
